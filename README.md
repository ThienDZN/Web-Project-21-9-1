# Ví dụ 1 — Login bằng email và header

Project độc lập cho `User`/`Role`, Spring Security form-login bằng email, MapStruct và Thymeleaf fragments (không dùng Layout Dialect).

```bash
EXAMPLE1_DEMO_PASSWORD='mật-khẩu-tự-chọn' mvn spring-boot:run
```

Đăng nhập bằng `demo.example1@test.local` và mật khẩu bạn vừa đặt. Kiểm tra: `mvn test`.
